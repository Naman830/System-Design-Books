# Roadmaps

Learning paths — *where to start, what order, and where it's enough.*

These are maps, not lessons. They tell you what to learn and when to move on; the depth lives in the topic folders they link to ([Libraries_Depth](../Libraries_Depth/), [System_Design](../System_Design/), [Database](../Database/), [Computer_Network](../Computer_Network/)).

| Roadmap | From → To |
|---|---|
| **[Backend (JavaScript → TypeScript)](./backend-roadmap.md)** | "I know JS" → design, build, ship and scale a production backend alone |

Each roadmap follows the same format: **phases → what to learn → why now → what to build → a checklist that says when you're allowed to move on.**
